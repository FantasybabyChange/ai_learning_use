# 线性代数练习

本目录包含线性代数的编程练习。

## 练习列表

### 基础练习
1. `exercise1_vector_operations.py`：向量运算练习
2. `exercise2_matrix_operations.py`：矩阵运算练习
3. `exercise3_special_matrices.py`：特殊矩阵练习

### 中级练习
4. `exercise4_eigenvalues.py`：特征值和特征向量练习
5. `exercise5_svd.py`：奇异值分解练习
6. `exercise6_pca.py`：主成分分析练习

### 高级练习
7. `exercise7_neural_network.py`：神经网络中的线性代数
8. `exercise8_attention.py`：注意力机制练习
9. `exercise9_recommendation_system.py`：推荐系统中的SVD应用

## 如何完成练习

1. 阅读练习文件中的注释和说明。
2. 在标记为`# TODO`的地方填写代码。
3. 运行脚本检查你的答案。
4. 如果遇到困难，可以参考`solutions/`目录中的参考答案。

## 提交练习

完成练习后，可以将你的代码提交到Git仓库，记录你的学习进度。

## 运行示例

```bash
python exercise1_vector_operations.py
```
