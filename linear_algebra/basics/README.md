## 1. 什么是向量

### 直觉理解

向量是**既有大小、又有方向**的量。

- **标量（Scalar）**：只有大小，没有方向。例如：温度 25°C、价格 100 元
- **向量（Vector）**：有大小 + 有方向。例如："向东走 3 公里"、"风速 10 m/s 向北"

### 数学定义

在 n 维空间中，向量是一组有序的数字（分量）：

```
v = [v₁, v₂, v₃, ..., vₙ]
```

- **1D 向量**（标量）：`v = [3]`
- **2D 向量**（平面）：`v = [3, 4]`，可以想象成坐标轴上一个箭头
- **3D 向量**（空间）：`v = [1, 2, 3]`，三维空间中的箭头
- **高维向量**：`v = [0.2, -0.5, 0.8, ...]`，AI 中词语、句子都用高维向量表示

### 列向量 vs 行向量

```
列向量（Column Vector）：竖着写    行向量（Row Vector）：横着写
     ┌ 1 ┐                          vᵀ = [1, 2, 3]
 v = │ 2 │
     └ 3 ┘
```

> 💡 **约定**：数学上默认向量是**列向量**；代码中（NumPy）默认是**行向量**（1D array）

## 2. 向量的表示

### 代码表示

```python
import numpy as np

# 创建向量
v = np.array([1, 2, 3])          # 行向量（shape: (3,)）
v_col = np.array([[1], [2], [3]]) # 列向量（shape: (3, 1)）

print(v.shape)      # (3,)
print(v_col.shape)  # (3, 1)
```

### 可视化（2D）

```
y
↑
4 |        ·  (3, 4)
3 |      /
2 |    /
1 |  /
0 +--------→ x
  0  1  2  3

向量 v = [3, 4]：从原点出发，指向坐标 (3, 4) 的箭头
```

## 3. 向量的基本运算

### 3.1 向量加法

**定义**：对应分量相加

```
v1 = [1, 2, 3]
v2 = [4, 5, 6]
v1 + v2 = [1+4, 2+5, 3+6] = [5, 7, 9]
```

**几何直觉**：将两个箭头首尾相接，结果是合力向量（平行四边形法则）

```
     v2
    ↗
   /
  +---→ v1
  ↘
   v1 + v2（沿对角线）
```

**代码**：
```python
v1 = np.array([1, 2, 3])
v2 = np.array([4, 5, 6])
result = v1 + v2  # [5, 7, 9]
```

---

### 3.2 标量乘法（数乘）

**定义**：用一个标量（数字）乘以向量的每个分量

```
k = 2
v = [1, 2, 3]
k × v = [2, 4, 6]
```

**几何直觉**：
- `k > 1`：向量**拉长**
- `0 < k < 1`：向量**缩短**
- `k < 0`：向量**反向**且缩放
- `k = -1`：向量**反向**，大小不变

**代码**：
```python
v = np.array([1, 2, 3])
result = 2 * v  # [2, 4, 6]
```

---

### 3.3 点积（内积）

**定义**：对应分量相乘后求和，结果是一个**标量**

```
v1 = [1, 2, 3]
v2 = [4, 5, 6]
v1 · v2 = 1×4 + 2×5 + 3×6 = 4 + 10 + 18 = 32
```

**几何公式**：

```
v1 · v2 = ||v1|| × ||v2|| × cos(θ)

其中 θ 是两个向量之间的夹角
```

**几何直觉**：
| 情况 | 点积值 | 含义 |
|------|--------|------|
| θ = 0°（同方向） | `> 0`（最大） | 完全相似 |
| θ = 90°（垂直） | `= 0` | 完全不相关 |
| θ = 180°（反方向） | `< 0`（最小） | 完全相反 |

> 🔑 **关键意义**：**点积衡量两个向量的相似度！** 这是 Attention 机制的核心！

**代码**：
```python
v1 = np.array([1, 2, 3])
v2 = np.array([4, 5, 6])

dot = np.dot(v1, v2)     # 32
dot = v1 @ v2            # 32（Python 3.5+ 矩阵乘法运算符）
dot = (v1 * v2).sum()    # 32（逐元素相乘再求和）
```

**在 Attention 中的应用**：
```
Attention 分数 = Q · Kᵀ / √d

Query 向量 Q 和 Key 向量 K 做点积，
点积越大 → 两个向量越相似 → 注意力分数越高
```

---

### 3.4 叉积（外积）

**定义**：仅在 3D 空间中定义，结果是一个**新向量**，方向垂直于原来两个向量

```
a = [1, 0, 0]（x轴方向）
b = [0, 1, 0]（y轴方向）
a × b = [0, 0, 1]（z轴方向，符合右手定则）
```

**计算公式**：
```
a × b = [a₂b₃ - a₃b₂,
         a₃b₁ - a₁b₃,
         a₁b₂ - a₂b₁]
```

**几何直觉**：叉积向量垂直于 a 和 b 所在的平面，大小 = `||a|| × ||b|| × sin(θ)`

> 💡 叉积在 AI 中不常用，了解即可。点积才是高频操作。

**代码**：
```python
a = np.array([1, 0, 0])
b = np.array([0, 1, 0])
cross = np.cross(a, b)  # [0, 0, 1]
```

## 4. 向量的范数（长度）

**范数（Norm）** = 向量的"大小"或"长度"，写作 `||v||`

### L1 范数（曼哈顿距离）

```
||v||₁ = |v₁| + |v₂| + ... + |vₙ|

例：v = [3, -4]
||v||₁ = |3| + |-4| = 7
```

### L2 范数（欧氏距离，最常用）

```
||v||₂ = √(v₁² + v₂² + ... + vₙ²)

例：v = [3, 4]
||v||₂ = √(3² + 4²) = √25 = 5
```

**几何直觉**：L2 范数就是向量箭头的实际长度（勾股定理）

### 无穷范数

```
||v||∞ = max(|v₁|, |v₂|, ..., |vₙ|)

例：v = [3, -4, 1]
||v||∞ = max(3, 4, 1) = 4
```

### 代码

```python
v = np.array([3, 4])

l1_norm = np.linalg.norm(v, ord=1)  # 7.0
l2_norm = np.linalg.norm(v)          # 5.0（默认 L2）
inf_norm = np.linalg.norm(v, ord=np.inf)  # 4.0
```

## 5. 单位向量与归一化

**单位向量**：L2 范数等于 1 的向量，只保留方向信息，去掉大小信息

**归一化（Normalization）**：将任意向量变成单位向量

```
v̂ = v / ||v||₂

例：v = [3, 4]
||v||₂ = 5
v̂ = [3/5, 4/5] = [0.6, 0.8]
||v̂||₂ = √(0.6² + 0.8²) = √(0.36 + 0.64) = 1.0 ✓
```

**在 AI 中的用途**：
- **余弦相似度**先对向量归一化，再做点积，结果就是余弦值（范围 -1 到 1）
- Transformer 中的 Layer Normalization 是对**激活值**做类似操作

```python
v = np.array([3, 4], dtype=float)
v_unit = v / np.linalg.norm(v)  # [0.6, 0.8]

# 余弦相似度 = 归一化后的点积
def cosine_similarity(a, b):
    return np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b))
```

## 6. 向量投影

**投影**：将向量 `a` 投影到向量 `b` 方向上，得到 `a` 在 `b` 方向上的"影子"

```
          a
         /|
        / |
       /  |
      /   ↓
----b------→  proj_b(a)（投影向量）

proj_b(a) = (a·b / ||b||²) × b
```

**标量投影**（长度）：
```
comp_b(a) = a·b / ||b||
```

**向量投影**：
```python
a = np.array([3, 4])
b = np.array([1, 0])  # x 轴方向

scalar_proj = np.dot(a, b) / np.linalg.norm(b)    # 3.0
vector_proj = (np.dot(a, b) / np.dot(b, b)) * b   # [3, 0]
```

**直觉**：在 Attention 机制中，Query 向 Key 方向投影的程度，就代表了相关性的强弱

## 7. 向量正交

**正交（Orthogonal）**：两个向量互相垂直，夹角 θ = 90°

**判断条件**：
```
a ⊥ b  ⟺  a · b = 0

例：a = [1, 0], b = [0, 1]
a · b = 1×0 + 0×1 = 0  → 正交 ✓
```

**正交的意义**：
- 正交向量之间**完全没有重叠的方向信息**（完全不相关）
- 在线性代数中，正交基（Orthogonal Basis）是最"干净"的坐标系
- 在神经网络中，希望不同特征的向量尽量正交，以减少冗余

```python
a = np.array([1, 0])
b = np.array([0, 1])

is_orthogonal = np.isclose(np.dot(a, b), 0)  # True
```

## 8. 向量在 AI / 大模型中的应用

### 8.1 词向量（Word Embedding）

将文字转化为高维向量，使得语义相似的词在向量空间中距离相近：

```
"猫"  → [0.2, -0.5, 0.8, 0.1, ...]   ← 高维向量
"狗"  → [0.3, -0.4, 0.7, 0.2, ...]   ← 与"猫"很接近
"汽车" → [-0.8, 0.9, -0.1, 0.6, ...]  ← 与"猫"距离很远

cos_sim("猫", "狗")  ≈ 0.95  （很相似）
cos_sim("猫", "汽车") ≈ 0.10  （不相似）
```

### 8.2 注意力机制中的点积

Self-Attention 的核心计算：

```
每个 token 生成 Q（Query）、K（Key）、V（Value）三个向量

注意力分数 = softmax( Q × Kᵀ / √d )

本质：Q 和 K 做点积 = 计算两个 token 的向量相似度
      分数越高 = 两个词越"相关"，需要更多互相关注
```

### 8.3 语义检索（RAG）

向量数据库中通过**余弦相似度**找最相关的文档：

```
用户提问  → Embedding 模型 → 查询向量 q
文档库    → Embedding 模型 → 文档向量 d₁, d₂, d₃, ...

相似度 = cos_sim(q, dᵢ) = q·dᵢ / (||q|| × ||dᵢ||)
返回相似度最高的 Top-K 文档
```

### 8.4 向量加减法的语义含义

著名的 Word2Vec 实验：

```
"国王" - "男人" + "女人" ≈ "女王"

向量的加减法，可以操控语义！
```
