# 矩阵分解

> 目标：理解为什么要把矩阵"拆开"，每种分解解决什么问题，以及在 AI 中的具体应用

---

## 为什么要学矩阵分解？

### 核心思想

矩阵分解 = **把一个复杂矩阵拆成几个简单矩阵的乘积**

类比：整数分解 12 = 3 x 4，矩阵也可以分解为更"基本"的矩阵组合。

### 为什么需要分解？

| 问题 | 直接做法 | 分解后做法 | 优势 |
|------|---------|-----------|------|
| 解方程 Ax=b | 求逆 A^(-1)b | LU/QR/Cholesky | 更快、更稳定 |
| 数据降维 | 无法直接做 | SVD/特征分解 | 保留主要信息 |
| 分析矩阵性质 | 看不出结构 | 分解后一目了然 | 揭示内在结构 |
| 推荐系统 | 评分矩阵稀疏 | SVD低秩近似 | 预测缺失值 |

### AI 中的核心地位

- **PCA** = 协方差矩阵的特征分解
- **LSA（潜在语义分析）** = 文本矩阵的 SVD
- **模型压缩** = 权重矩阵的低秩 SVD 近似
- **Gaussian Process** = 协方差矩阵的 Cholesky 分解
- **数值稳定的训练** = QR 分解替代直接求逆

## 1. 特征分解

### 直觉理解

特征向量是矩阵变换中**方向不变**的特殊向量，特征值是缩放倍数：

```
A * v = lambda * v

v: 特征向量（方向不变）
lambda: 特征值（缩放倍数）
```

几何意义：矩阵 A 对大多数向量都会改变方向，但对特征向量只做拉伸/压缩。

### 分解形式

对称矩阵可以完美分解：

```
A = Q * Lambda * Q^T

Q: 特征向量组成的正交矩阵
Lambda: 特征值组成的对角矩阵
```

### AI 应用

- **PCA**：对协方差矩阵做特征分解，特征向量=主成分方向，特征值=该方向的方差
- **谱聚类**：用拉普拉斯矩阵的特征向量做聚类
- **PageRank**：转移矩阵的主特征向量=稳态排名

### 代码

运行 `eigen_decomposition.py`，包含特征分解验证、PCA 实现、幂迭代法。

## 2. 奇异值分解 SVD

### 直觉理解

SVD 是**最通用的矩阵分解**，任何矩阵都能分解：

```
A = U * Sigma * V^T

U: 左奇异向量（输出空间的基）
Sigma: 奇异值（重要性排序）
V^T: 右奇异向量（输入空间的基）
```

几何意义：任何线性变换都可以分解为 **旋转 -> 缩放 -> 旋转** 三步。

### 为什么比特征分解更重要？

- 特征分解要求方阵，SVD 适用于任意 m x n 矩阵
- 特征分解可能失败（非对称矩阵），SVD 永远存在
- 奇异值天然排序，方便做截断（低秩近似）

### AI 应用

- **低秩近似 / 模型压缩**：只保留前 k 个奇异值，大幅减少参数量
- **推荐系统**：用户-物品评分矩阵的 SVD 分解，预测缺失评分
- **降维**：等价于 PCA（数据中心化后的 SVD = PCA）
- **文本分析 LSA**：词-文档矩阵的 SVD 发现潜在语义
- **图像压缩**：保留少量奇异值即可重建图像

### 代码

运行 `svd.py`，包含 SVD 验证、图像压缩、推荐系统、降维示例。

## 3. QR 分解

### 直觉理解

把矩阵分解为**正交矩阵 x 上三角矩阵**：

```
A = Q * R

Q: 正交矩阵（列向量互相垂直，Q^T * Q = I）
R: 上三角矩阵
```

几何意义：Gram-Schmidt 正交化过程的矩阵表示——把一组线性无关的向量变成正交基。

### 为什么有用？

- 正交矩阵条件数=1，数值最稳定
- 解方程 Rx = Q^T b 只需回代，O(n^2)
- 比直接求逆稳定得多

### AI 应用

- **最小二乘法**：QR 分解是求解超定方程的标准方法
- **Batch Normalization** 的数值稳定实现
- **RNN/LSTM 训练**：用正交矩阵初始化权重，缓解梯度消失
- **特征值计算**：QR 算法是求特征值的工业标准方法

### 代码

运行 `qr_decomposition.py`，包含 Gram-Schmidt、Householder 变换、解方程示例。

## 4. Cholesky 分解

### 直觉理解

专门针对**对称正定矩阵**的高效分解：

```
A = L * L^T

L: 下三角矩阵
```

类比：正数的平方根。对称正定矩阵的"矩阵平方根"。

### 适用条件

- 矩阵必须对称（A = A^T）
- 矩阵必须正定（所有特征值 > 0）
- 常见场景：协方差矩阵、Hessian 矩阵、核矩阵

### 为什么选它？

- 计算量只有 LU 分解的一半
- 不需要选主元，天然稳定
- 存储只需一半空间（对称性）

### AI 应用

- **多元高斯分布**：采样 z = L * eps，其中 eps ~ N(0,I)
- **Gaussian Process**：协方差矩阵的 Cholesky 分解用于采样和预测
- **优化算法**：牛顿法中 Hessian 矩阵的分解求解
- **卡尔曼滤波**：状态估计中的协方差更新

### 代码

## 5. 四种分解对比

| 分解 | 形式 | 适用矩阵 | 复杂度 | AI 典型用途 |
|------|------|---------|--------|------------|
| 特征分解 | Q*L*Q^T | 对称方阵 | O(n^3) | PCA、谱聚类 |
| SVD | U*S*V^T | 任意 m x n | O(mn^2) | 降维、推荐、压缩 |
| QR | Q*R | 任意 m x n | O(mn^2) | 最小二乘、稳定求解 |
| Cholesky | L*L^T | 对称正定 | O(n^3/3) | 高斯采样、GP |

选择原则：
- 通用降维/分析 → SVD
- 对称矩阵的特征分析 → 特征分解
- 解方程/最小二乘 → QR
- 对称正定矩阵 → Cholesky
