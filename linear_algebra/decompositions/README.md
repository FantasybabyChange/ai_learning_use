# 矩阵分解

本目录包含矩阵分解方法的学习材料。

## 内容

- `eigen_decomposition.py`：特征值分解示例。
- `svd.py`：奇异值分解（SVD）示例。
- `qr_decomposition.py`：QR分解示例。
- `cholesky_decomposition.py`：Cholesky分解示例。

## 学习目标

1. 掌握特征值和特征向量的概念及计算方法。
2. 理解奇异值分解（SVD）的原理和应用。
3. 学习QR分解和Cholesky分解的用途。

## 运行示例

```bash
python eigen_decomposition.py
```
